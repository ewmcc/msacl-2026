A beginner's introduction to Python. The notebook [python_demo.ipynb](python_demo.ipynb):

1. Generates a bimodal dataset: 50 values around 10 and 50 values around 20.
2. Summarizes it with pandas (mean and standard deviation).
3. Plots it as a histogram with matplotlib.

Each step explains the Python it uses: variables, lists, loops, functions, and packages.
